Linux Network Configuration

Learn how to configure network interfaces, assign IP addresses, manage routing tables, and set up DNS on Linux systems. We cover both the legacy ifconfig approach and the modern ip suite, along with NetworkManager tools.

🕐 ~45 min 🎯 Beginner 📝 5 Quiz Questions 🧪 1 Lab Exercise

📌 Overview

Networking in Linux is managed at multiple levels: the kernel handles the network stack, while userspace tools configure interfaces, routes, and services. The two primary toolsets are:

  • iproute2 — the modern suite: ip, ss, tc
  • NetworkManager — the high-level daemon: nmcli, nmtui
  • net-tools (legacy) — ifconfig, route, netstat
💡
Modern vs Legacy
Always prefer ip over ifconfig and ss over netstat. The net-tools package is deprecated on most modern distributions.

🔌 Network Interfaces

Every network connection is represented as an interface. Common naming conventions:

InterfaceTypeDescription
loLoopbackInternal 127.0.0.1 — always present
eth0 / ens3EthernetWired NIC — legacy / predictable naming
wlan0 / wlp2s0WirelessWi-Fi adapter
virbr0BridgeVirtual bridge for VMs
docker0BridgeDocker network bridge
tun0 / tap0VirtualVPN tunnel interfaces
bash
$ ip link show 1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00 2: ens3: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc fq_codel state UP link/ether 52:54:00:12:34:56 brd ff:ff:ff:ff:ff:ff
$ ip addr show 2: ens3: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc fq_codel state UP inet 192.168.1.100/24 brd 192.168.1.255 scope global ens3
$ ip -s link show ens3 # show statistics

🛠️ The ip Command

The ip command from the iproute2 package is the primary tool for network configuration in modern Linux.

ip addr add
Assign an IP address to an interface
ip addr add 192.168.1.10/24 dev ens3
ip addr del
Remove an IP address from an interface
ip addr del 192.168.1.10/24 dev ens3
ip link set up/down
Bring interface up or down
ip link set ens3 up
ip route add
Add a static route
ip route add 10.0.0.0/8 via 192.168.1.1
ip route show
Display routing table
ip route show
ip neigh show
Show ARP/neighbor table
ip neigh show
⚠️
Changes are not persistent
Changes made with ip are lost after reboot. To persist them, use NetworkManager (nmcli) or edit configuration files in /etc/netplan/ (Ubuntu) or /etc/sysconfig/network-scripts/ (RHEL).
bash — configure static IP
# Assign static IP $ sudo ip addr add 192.168.1.50/24 dev ens3 $ sudo ip link set ens3 up $ sudo ip route add default via 192.168.1.1
# Verify configuration $ ip addr show ens3 $ ip route show default via 192.168.1.1 dev ens3 192.168.1.0/24 dev ens3 proto kernel scope link src 192.168.1.50

⚙️ NetworkManager — nmcli

NetworkManager is the standard network management daemon on most modern Linux distros. nmcli is its command-line interface, and nmtui offers a TUI.

bash — nmcli essentials
# List all connections $ nmcli connection show
# Show device status $ nmcli device status
# Add a static IP connection $ sudo nmcli con add type ethernet \ con-name "static-ens3" \ ifname ens3 \ ipv4.method manual \ ipv4.addresses "192.168.1.50/24" \ ipv4.gateway "192.168.1.1" \ ipv4.dns "8.8.8.8 8.8.4.4"
# Activate the connection $ sudo nmcli con up static-ens3
# Switch to DHCP $ sudo nmcli con mod static-ens3 ipv4.method auto $ sudo nmcli con up static-ens3

🗺️ Routing & Next-Hop Decision

Routing determines where network packets are sent. The Linux kernel evaluates destination IPs against the routing table using the Longest Prefix Match (LPM) algorithm.

bash — routing commands
# Show routing table $ ip route show default via 192.168.1.1 dev ens3 proto dhcp src 192.168.1.100 metric 100 192.168.1.0/24 dev ens3 proto kernel scope link src 192.168.1.100
# Add a static route $ sudo ip route add 10.10.0.0/16 via 192.168.1.254
# Delete a route $ sudo ip route del 10.10.0.0/16
# Enable IP forwarding (routing between interfaces) $ sudo sysctl -w net.ipv4.ip_forward=1 # Persist: echo 'net.ipv4.ip_forward=1' >> /etc/sysctl.conf

🔍 DNS Configuration & Resolver Benchmark

DNS resolver configuration is managed via /etc/resolv.conf or systemd-resolved.

bash — DNS commands
# View current DNS settings $ cat /etc/resolv.conf nameserver 8.8.8.8 nameserver 8.8.4.4 search localdomain
# Query DNS records $ dig A google.com $ dig +short MX gmail.com $ nslookup 8.8.8.8
# systemd-resolved $ resolvectl status $ resolvectl query google.com

🧪 Lab Exercise

🧪
Lab 01 — Configure a Static IP with NetworkManager
Estimated time: 15 minutes · Root access required
1
Identify your network interface
Run ip link show to list all interfaces. Note down the name of your Ethernet interface (e.g., ens3, eth0, enp3s0).
2
Check current IP configuration
Run ip addr show and ip route show to document the current state.
3
Create a static connection profile
Use nmcli con add to create a new static-IP connection profile on your interface. Use IP 192.168.1.200/24, gateway 192.168.1.1, DNS 8.8.8.8.
4
Activate the connection
Run nmcli con up <con-name>. Verify with ip addr show that the new IP is assigned.
5
Test connectivity
Run ping -c 4 8.8.8.8 to test internet connectivity, and dig google.com to verify DNS resolution.
6
Restore DHCP
Modify the connection: nmcli con mod <con-name> ipv4.method auto then reactivate it.
