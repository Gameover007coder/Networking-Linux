UFW — Uncomplicated Firewall

UFW provides a simplified frontend to iptables, making firewall configuration easy and accessible on Ubuntu and Debian-based systems. Despite its simplicity, it's fully capable for most use cases.

🕐 ~35 min 🎯 Beginner 📝 5 Quiz Questions

📌 Overview

UFW (Uncomplicated Firewall) ships with Ubuntu and is the recommended firewall tool for Debian-based systems. It wraps iptables with a much simpler syntax.

  • Default policy: deny all incoming, allow all outgoing
  • Rule persistence: all rules are automatically saved
  • App profiles: pre-defined rules for common services
  • IPv6 support: handles both IPv4 and IPv6
⚠️
Conflict with firewalld/iptables
Don't run UFW alongside firewalld or manage iptables directly while UFW is active. Use only one firewall management tool at a time.

🔧 Setup & Enable

bash — UFW setup
# Install UFW (if not already present) $ sudo apt install ufw
# Check current status $ sudo ufw status verbose Status: inactive
# IMPORTANT: Allow SSH BEFORE enabling UFW! $ sudo ufw allow ssh Rules updated Rules updated (v6)
# Set default policies $ sudo ufw default deny incoming $ sudo ufw default allow outgoing
# Enable UFW $ sudo ufw enable Command may disrupt existing ssh connections. Proceed with operation (y|n)? y Firewall is active and enabled on system startup
# Disable UFW $ sudo ufw disable
# Reset all rules $ sudo ufw reset

📝 Allow & Deny Rules

bash — UFW allow/deny rules
# Allow by port number $ sudo ufw allow 80/tcp $ sudo ufw allow 443/tcp $ sudo ufw allow 8080
# Allow by service name $ sudo ufw allow http $ sudo ufw allow https $ sudo ufw allow ftp
# Deny a port $ sudo ufw deny 23/tcp
# Allow from specific IP $ sudo ufw allow from 203.0.113.10
# Allow from IP to specific port $ sudo ufw allow from 203.0.113.10 to any port 22
# Allow from subnet $ sudo ufw allow from 192.168.1.0/24 to any port 3306
# Delete a rule (by number) $ sudo ufw status numbered $ sudo ufw delete 3
# Delete by rule specification $ sudo ufw delete allow 8080

📦 Application Profiles

UFW includes application profiles stored in /etc/ufw/applications.d/. Packages like OpenSSH and Apache install their own profiles.

bash — application profiles
# List available application profiles $ sudo ufw app list Available applications: Apache Apache Full Apache Secure OpenSSH Nginx Full
# Show profile details $ sudo ufw app info 'Apache Full' Profile: Apache Full Title: Web Server (HTTP,HTTPS) Description: Apache web server Ports: 80,443/tcp
# Allow an application profile $ sudo ufw allow 'Nginx Full' $ sudo ufw allow 'OpenSSH'
# Delete application profile rule $ sudo ufw delete allow 'Apache'

⚡ Advanced Rules

bash — advanced UFW
# Allow with protocol specification $ sudo ufw allow proto tcp from 192.168.1.0/24 to any port 22
# Limit (rate-limit for brute-force protection) $ sudo ufw limit ssh/tcp Rules updated # Limits to 6 connections per 30 seconds from same IP
# Insert rule at specific position $ sudo ufw insert 1 allow from 10.0.0.0/8
# Deny outgoing to specific IP $ sudo ufw deny out to 198.51.100.0/24
# Allow port range $ sudo ufw allow 6000:6100/tcp

📋 Logging

bash — UFW logging
# Enable logging $ sudo ufw logging on $ sudo ufw logging low # low | medium | high | full
# View UFW logs $ sudo tail -f /var/log/ufw.log [UFW BLOCK] IN=ens3 OUT= SRC=203.0.113.5 DST=192.168.1.100 PROTO=TCP DPT=22
# UFW logs are also in syslog $ sudo grep UFW /var/log/syslog | tail -20
# Check full status $ sudo ufw status verbose

🧪 Lab Exercise

🧪
Lab 04 — Secure an Ubuntu Web Server with UFW
Estimated time: 15 minutes · Ubuntu/Debian
1
Allow SSH before enabling
Always run sudo ufw allow OpenSSH FIRST to avoid locking yourself out.
2
Set default deny policies
Set default incoming to deny and outgoing to allow.
3
Enable the firewall
Run sudo ufw enable and confirm the prompt.
4
Allow web traffic
Allow the 'Nginx Full' or 'Apache Full' application profile, or manually allow 80 and 443.
5
Rate-limit SSH
Run sudo ufw limit ssh to enable brute-force protection for SSH.
6
Enable logging and verify
Enable medium logging with sudo ufw logging medium and check sudo ufw status verbose.
