firewalld — Zone-Based Firewall

firewalld is the default firewall daemon on RHEL, CentOS, Fedora, and openSUSE. It provides a dynamic firewall with zone-based management, eliminating the need to restart the firewall when rules change.

🕐 ~50 min 🎯 Intermediate 📝 5 Quiz Questions

📌 Overview

firewalld uses a two-tier system: runtime (immediate, not persistent) and permanent (survives reboots). It sits on top of nftables (or iptables on older systems) and manages rules dynamically without requiring a full reload.

bash — firewalld management
# Start and enable firewalld $ sudo systemctl start firewalld $ sudo systemctl enable firewalld
# Check status $ sudo firewall-cmd --state running
# Reload after permanent changes $ sudo firewall-cmd --reload
# Get all information $ sudo firewall-cmd --list-all
💡
Runtime vs Permanent
Without --permanent, changes apply immediately but are lost after reboot. With --permanent, changes are saved but don't take effect until --reload. Use both together, or add --runtime-to-permanent to save current state.

🗺️ Zones

Zones define trust levels for network connections. Each interface is assigned to a zone.

ZoneTrust LevelDefault Behavior
dropMinimumAll incoming dropped, no reply
blockVery LowIncoming rejected with ICMP message
publicLowOnly selected services allowed (default)
externalLowLike public + masquerade enabled
dmzMediumLimited external access to internal
workMedium-HighMost connections trusted
homeHighHome network — more services allowed
internalHighInternal network — similar to home
trustedMaximumAll connections accepted
bash — zone management
# List all zones $ sudo firewall-cmd --get-zones block dmz drop external home internal public trusted work
# Get default zone $ sudo firewall-cmd --get-default-zone public
# Set default zone $ sudo firewall-cmd --set-default-zone=home
# Assign interface to zone $ sudo firewall-cmd --zone=public --add-interface=ens3 --permanent
# List zone details $ sudo firewall-cmd --zone=public --list-all

⚙️ Services

firewalld comes with pre-defined service definitions that bundle ports and protocols by name (e.g., "http" = tcp/80).

bash — service management
# List available services $ sudo firewall-cmd --get-services
# List services in current zone $ sudo firewall-cmd --list-services dhcpv6-client ssh
# Allow HTTP and HTTPS (permanent) $ sudo firewall-cmd --zone=public --add-service=http --permanent $ sudo firewall-cmd --zone=public --add-service=https --permanent $ sudo firewall-cmd --reload
# Remove a service $ sudo firewall-cmd --zone=public --remove-service=ftp --permanent
# Check if service is active $ sudo firewall-cmd --zone=public --query-service=http yes

🔌 Ports & Protocols

When no predefined service exists, open specific ports directly.

bash — port management
# Open port 8080/tcp $ sudo firewall-cmd --zone=public --add-port=8080/tcp --permanent
# Open a port range $ sudo firewall-cmd --zone=public --add-port=6000-6100/udp --permanent
# Remove a port $ sudo firewall-cmd --zone=public --remove-port=8080/tcp --permanent
# List all open ports $ sudo firewall-cmd --zone=public --list-ports 8080/tcp 6000-6100/udp
# Allow ICMP type $ sudo firewall-cmd --zone=public \ --add-icmp-block-inversion $ sudo firewall-cmd --zone=public \ --add-icmp-block=echo-request

📜 Rich Rules

Rich rules provide fine-grained control with source/destination IPs, logging, and rate-limiting — beyond simple service/port rules.

bash — rich rules
# Allow SSH only from specific IP $ sudo firewall-cmd --zone=public \ --add-rich-rule='rule family=ipv4 source address="203.0.113.10" service name="ssh" accept' \ --permanent
# Block a specific IP address $ sudo firewall-cmd --zone=public \ --add-rich-rule='rule family=ipv4 source address="198.51.100.0/24" reject' \ --permanent
# Rate-limit SSH connections with logging $ sudo firewall-cmd --zone=public \ --add-rich-rule='rule service name="ssh" log prefix="SSH_ATTEMPT " level="info" limit value="3/m" accept' \ --permanent
# Port forwarding: 8080 → 80 $ sudo firewall-cmd --zone=public \ --add-rich-rule='rule family="ipv4" forward-port port="8080" protocol="tcp" to-port="80"' \ --permanent
# List rich rules $ sudo firewall-cmd --zone=public --list-rich-rules

🔄 Masquerade & Port Forwarding

bash — NAT & forwarding
# Enable masquerading (NAT) on external zone $ sudo firewall-cmd --zone=external --add-masquerade --permanent $ sudo firewall-cmd --zone=external --query-masquerade yes
# Port forwarding: redirect port 80 to 192.168.1.10:80 $ sudo firewall-cmd --zone=public \ --add-forward-port=port=80:proto=tcp:toaddr=192.168.1.10 \ --permanent
# Enable IP masquerade for internal → external $ sudo firewall-cmd --permanent --direct \ --add-rule ipv4 nat POSTROUTING 0 \ -o ens3 -j MASQUERADE
