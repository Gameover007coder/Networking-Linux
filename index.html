Curriculum

All Learning Modules

Work through each module sequentially, or jump to the topic you need.

🌐
Module 01 Beginner

Network Configuration

Configure network interfaces, IP addresses, routing, DNS, and DHCP on Linux systems using ip, nmcli, and nmtui.

ip nmcli DNS routing
→
🔥
Module 02 Intermediate

iptables & nftables

Master Linux's powerful packet filtering framework. Create rules, manage chains, and build complete firewall policies using iptables and modern nftables.

iptables nft chains NAT
→
🛡️
Module 03 Intermediate

firewalld

Use firewalld's dynamic zone-based firewall management on RHEL/CentOS/Fedora. Configure services, ports, rich rules, and masquerading.

firewall-cmd zones services
→
🔒
Module 04 Beginner

UFW — Uncomplicated Firewall

Quickly manage firewall rules on Ubuntu/Debian with UFW. Set policies, allow/deny services, and use application profiles.

ufw profiles logging
→
📡
Module 05 Intermediate

Network Monitoring & Troubleshooting

Diagnose network issues using ss, tcpdump, nmap, Wireshark, and more. Analyze traffic, check connectivity, and monitor bandwidth.

ss tcpdump nmap ping
→
🔑
Module 06 Advanced

VPN & Tunneling

Set up secure tunnels with OpenVPN and WireGuard. Configure site-to-site VPNs, SSH tunneling, and IP-in-IP encapsulation.

WireGuard OpenVPN SSH
→
⚔️
Module 07 Advanced

Network Security Hardening

Harden Linux network stack against attacks: SSH hardening, fail2ban, port knocking, kernel parameters, and SELinux basics.

fail2ban sshd SELinux sysctl
